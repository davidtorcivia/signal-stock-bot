System prompt

LLM intent routing

When enabled, any message in this chat that isn't a prefixed command goes to the LLM with all allowed bot commands and MCP tools available. Replaces the default NLP fallback. DMs trigger always; groups trigger only when the bot is @mentioned.

Emoji reactor

Only effective when the global reactor is enabled at /admin/llm. Uncheck to silence reactions in this specific chat without disabling them globally.

Natural response

When on (and the reactor is enabled here), the reactor's LLM call also considers whether the message warrants a real text reply — for open-ended questions it can answer or obvious follow-ups to its own messages without an @mention or quote-reply. The writer model still gets a final say and may stay silent. Requires the global switch at /admin/llm and a working reactor.

Memory

When on, the LLM gets remember / forget tools alongside recall so it can store durable facts about people, the room, or free-text entities. Saved memories auto-inject into future replies in this chat. Off makes recall read-only — the LLM can use existing memories but can't add new ones. Turn off in chats where you want to view memories without letting the model edit them.

Off by default. When on, the reactor's per-message LLM call also gets a note_memory tool, so it can extract durable facts from messages even when the main bot isn't called. Reactor writes land at confidence 0.6 and promote to 1.0 only after corroborations from at least three distinct speakers — single- user repetition can't self-promote a hallucination. Privacy- sensitive: only enable in chats where passive learning is appropriate.

Heads-up: if you turn this on, you may need to bump Reactor max tokens at /admin/llm (default 50). The reactor LLM now picks between three tools and its arguments — a 50-token budget can truncate the note_memory JSON. 200 is a safer floor when this flag is on.
